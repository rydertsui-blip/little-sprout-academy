# 小芽家庭学习岛

挂在主站 `/family/` 下的本地优先儿童学习 PWA，面向新加坡小学一年级至二年级。唯一交付形态是 Web PWA，支援 iPhone、iPad、Android 平板；没有桌面版或原生 App 版。

## 当前能力

- 家长 PIN 解锁家庭空间，家长档案和全部学习记录以 AES-GCM 加密后保存在本地。
- 重新打开网页后需要再次解密；主页和家长看板都提供“锁定”入口。
- 家长可创建多个孩子档案，填写名字并选择头像。
- 家长可修改孩子名字和头像；删除孩子前会提示先导出学习记录。
- 孩子在 iPhone、iPad 或 Android 平板上选择自己的档案，不创建独立账号。
- 数学、华文、英语各有 8 题分支式入学小测：连续答对会升级题目难度，答错会回退到更基础题目。
- 30 个知识点、210 道固定题：180 道三选一和 30 道三对点击配对。
- 每科诊断第一题是配对方块；点错可立即重试，三对完成才记录一次作答。
- BKT 知识追踪、前置知识关系、证据门槛和固定复习间隔。
- 家长看板可查看每科练习数量、较稳定/已巩固数量、下一步建议和作答总数。
- 家长可调整每轮题数，并重做任一科目起点小试。
- 内容包和学习记录仅保存在当前设备；学习记录加密存储，不向服务器上传。
- 支持中断后恢复小测，退出或刷新不会重复计算已经作答的题目。
- 支持导出和导入家庭学习备份。
- PWA 离线应用壳，联网后自动缓存静态资源。
- 12 个基础汉字笔顺动画与描写测验，使用本地 Hanzi Writer 数据。
- 22 个中英文跟读提示；支持麦克风录音、停止、自动回放、重录和下一个。
- 麦克风不支持或拒绝权限时保留听示范；录音只留在当前页面，不上传。
- 家长看板显示三科下一步建议、近七天独立答对/提示数据和逐题 CSV。
- 家长看板分别显示 App、内容和资料 schema 版本，并显示本机储存用量和接近上限警告。
- 每个孩子可独立开启高对比和大字显示。
- 55 段普通话和英语录音优先离线播放。
- `pilot-5` 内容包有逐题 MOE 官方来源、PDF hash、逐页原文证据、exact/broad 映射和 SHA-256 签名。
- 210 个已发布题目 ID 有历史快照；删除旧 ID 会导致内容验证失败。

## 内容文件

- `src/content/skills.ts`：知识点、年级范围、前置关系、MOE 来源。
- `src/content/math.ts`：12 个数学知识的固定题生成规则。
- `src/content/language.ts`：华文和英语固定题。
- `src/content/matching.ts`：华文、英语和数学的三对点击配对题。
- `src/content/catalog.ts`：内容装配与完整性校验。
- `CONTENT_VERSION = pilot-5`，家长看板显示当前内容版本、官方来源状态和“人工课纲复核未进行”。

## 官方来源验证

课程目标只使用 `https://www.moe.gov.sg/` 的官方 PDF。来源清单、44 条 outcome 和自动覆盖率矩阵位于 `sources/official/`。

```bash
npm run verify:sources
npm run coverage:sources
```

`verify:sources`会校验PDF SHA-256、页数、指定页和原文引文；`build`会先运行这层门禁。详细规则见根目录 `官方課程來源與驗證規範.md`。

## 内容发布门

```bash
npm run verify:content
```

当前会验证 210 道题的 schema、答案、配对键、来源、自动检查状态和内容 SHA-256。修改任何题目、答案或解释后，必须人工复核，再执行：

```bash
npm run update:content
```

生产构建会自动先运行 `verify:content`，签名不一致时不会生成新包。

课程范围参考：

- [MOE 2021 Mathematics Syllabus](https://www.moe.gov.sg/media/files/primary/92bff26d-b2b4-4535-b868-b8415c744b91.pdf)

## 学习算法

`BKT 技能概率 + 前置知识关系 + 证据门 + 固定间隔复习`。

- 练习保持约 80% 预测成功率。
- 同一道题重复出现不会增加掌握证据。
- “暂稳”至少需要 3 个不同题目独立正确。
- “稳固”至少需要 4 个不同题目，并包含一次按间隔完成的隔日复习。
- 孩子结果只显示“还没看清、正在学、比较稳定、已经巩固”，不给孩子贴全局年级标签。
- 不使用 LLM；算法是固定、可解释的统计规则。

## 准确性和质量

发布前执行：

```bash
npm test
npm run build
```

自动测试覆盖：

- BKT 公式、证据门和复习重置
- MOE 官方 URL、PDF SHA-256、页数和逐页原文证据
- 每个技能、活动和题目的官方 outcome 引用
- 前置知识无环
- 每题三个互不重复选项、唯一正确答案、解释存在
- 每道配对题三个稳定配对、左右标签不重复、完成前可重试
- 算术题独立重算
- 配对数学算式、位值、分数、金钱和图形独立重算
- 拼音声母、韵母、完整音节和声调用 `pinyin-pro` 独立校验
- 家长 PIN、双次解锁、建孩子、完整 8 题小测、看板和设置
- 加密存储、锁定、损坏数据恢复、版本迁移和会话中断恢复

真实触摸审核另行覆盖：

- iPhone 直向/横向、iPad 各方向、Android 平板直向/横向
- 横向溢出与 44 px 最小触摸目标
- 真实 `touchscreen.tap`、重复触摸保护
- 三科入口、配对题故意配错与重试、完整诊断、家长二次 PIN、重新加载锁定、断网重载
- 所有可见图片均可加载，浏览器无 console/page error

## 已知边界

- 这是单设备本地优先版本，尚未接入云同步或跨设备家长看板。
- 家长 PIN 与 AES-GCM 加密阻止普通误入和明文读取，但它仍不是服务端身份系统；掌握 PIN 的人可以进入家庭空间。
- 内容已做结构、规则和拼音自动校验，正式对外前仍应由熟悉新加坡 P1/P2 的教师做人工审校。
- 目前 44 条官方目标中仍有 11 条没有对应内容；另有 2 个华文技能标为课外补充，不纳入官方覆盖。产品明确标为部分覆盖，不是完整 P1/P2 课程。
- AI 功能按你的决定暂缓。
